# Platform Payout Reconciler (ระบบตรวจสอบและกระทบยอดเงินเข้า)

ระบบตรวจสอบและกระทบยอดเงินเข้า (Reconciliation & Audit) สำหรับร้านค้าบน E-commerce แพลตฟอร์ม (TikTok Shop, Shopee, Lazada) ช่วยตรวจจับความผิดปกติทางการเงิน การแอบปล่อยเงินโอน รายการค้างจ่าย และส่วนต่างค่าธรรมเนียม

## 🌟 ฟังก์ชันหลัก (Key Features)

1. **Drag & Drop Upload:**
   - ช่องที่ 1: รายการรอเงินเข้า (Pending Settlement Report เช่น ไฟล์รอชำระเงินของ TikTok Shop)
   - ช่องที่ 2: รายการเงินเข้าจริง (Settled Transactions / Income Statement)
2. **ตรวจจับความผิดปกติ 4 มิติ:**
   - 🚨 **เงินเข้าไม่ตรงนัด (Ghost Payouts):** ตรวจจับรายการที่เงินโอนเข้ามา แต่ไม่เคยปรากฏในตารางรอเงินเข้าของวันนั้น (เช่น กรณีที่ยื่น Ticket แล้วระบบแอบโอนเงินเข้ามาตอนเย็น)
   - ⏳ **ถึงกำหนดแต่ไม่ยอมโอน (Overdue / Held):** รายการที่ส่งมอบแล้วหรือถึงกำหนดจ่ายแล้ว แต่ไม่มีในรายงานเงินเข้าจริง
   - ⚠️ **ยอดเงินไม่ตรงกัน (Mismatch / Fee Discrepancy):** ตรวจจับส่วนต่างระหว่างยอดประมาณการ vs ยอดโอนจริง
   - 🟢 **ตรงกันตามนัด (Matched):** ข้อมูลตรงกันสมบูรณ์
3. **เครื่องมือช่วยเหลือผู้ขาย:**
   - **ปุ่มคัดลอกเลขเคสเปิดตั๋ว:** รวม Order ID ที่มีปัญหาทั้งหมดเพื่อนำไปวางในแชทซัพพอร์ตได้ทันที
   - **ส่งออกรายงาน Excel (Multi-sheet):** สร้างรายงานสรุปและชีตรายการผิดปกติ
   - **Offline-ready & Privacy First:** ประมวลผลบนเบราว์เซอร์ 100% ไม่ส่งข้อมูลการเงินออกสู่ภายนอก

## 🚀 การติดตั้งและใช้งานแบบ Local

สามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้ทันที หรือรันผ่าน Local Server:

```bash
# เริ่มต้นเซิร์ฟเวอร์
node server.js
# หรือดับเบิลคลิกไฟล์ start_app.bat บน Windows
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
